Work

Lead Engineer — Manhattan Associates   2020–2025

Manhattan Associates makes Manhattan Active® — a cloud-native SaaS suite covering Supply Chain, Warehouse Management, and Transportation Management for large retailers and logistics companies. The platform runs on GCP, uses Google Pub/Sub for async messaging, and exposes everything through REST APIs with OAuth2/SAML-based access management. My team worked on the TMS side: trip planning, carrier assignment, real-time tracking, and the event pipeline underneath all of it.

The most interesting problem I worked on was latency. The trip planning screen was loading in 15 seconds for dispatchers managing 100,000+ concurrent trips. That is not a typo. After profiling we found the culprit: every page load was hammering the PC*MILER routing API for mileage data that had not changed since last week. We built a Hazelcast cache in front of it, tuned HikariCP connection pooling, and got the load time to 2 seconds.

I also led the mobile app we built for drivers — Ionic/Angular, Firebase for real-time updates, talking to 25+ backend APIs I had also written. About 1,000 drivers use it daily. When I started that project I had never shipped a mobile app. I read the docs and figured it out.

On the infrastructure side: I worked on shipment processing and tracking message pipelines built on RabbitMQ, set up Elasticsearch for shipment search handling 1M+ daily queries, and wrote the EDI pipeline (X12 204/214/210/997) for invoice generation and carrier payment. I was on the on-call rotation for P1/P2 incidents across 500+ enterprise clients, which is where you really learn how systems break.

A few years in I started leading the Dispatch team, doing architecture reviews, and sitting in on hiring panels. I left in 2025 to look for something new.
